Entry for the [make.fun bounty](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990): one funny single-line one-star review written by a house cat about its human.

## What it does

`main.py` writes a single line (141 characters) to `/output/entry.txt`:

> One star. The food bowl sat empty for eleven whole minutes, so I sat on his keyboard and deleted his meeting. Would not recommend this human.

The line keeps the deadpan shape of a real one-star review while the complaint goes somewhere only a cat would go: the food bowl, the laptop keyboard, and a verdict on the human.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
